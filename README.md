Almost everything I release starts as a side project. I find a workflow pain point, build a fix, then open-source it.

### VS Code Extensions & .NET Tooling

| Project | Description |
|---|---|
| [safe-to-send](https://github.com/chaluvadis/safe-to-send) | Scan selected code before AI sharing. Built after I almost pasted secrets into a prompt. |
